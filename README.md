**Gap-aware hidden Markov modelling of hard–soft count contrasts in fragmented X-ray time series**

Raffaele Mattera and Andrea Nigri

##

This repository accompanies the manuscript "Gap-aware hidden Markov modelling of hard–soft count contrasts in fragmented X-ray time series". This project develops a gap-aware Hidden Markov Model (HMM) framework for fragmented X-ray photon-count time series. The proposed methodology accounts for observational gaps and partial exposure while preserving the temporal dynamics of the underlying latent Markov process. Three count-based emission specifications are considered:

- Skellam emissions for hard–soft count contrasts;
- Independent bivariate Poisson emissions;
- Correlated bivariate Poisson emissions.
